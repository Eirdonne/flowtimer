# FlowTimer delivery outcomes

- [ ] The app provides a floating always-on-top timer window with black 90% opacity styling, white sans-serif text, rounded corners, and a progress bar that depletes as a countdown finishes.
- [ ] A single click starts or pauses the timer, and a double click resets and starts the selected interval.
- [ ] The app supports count-up to infinity and count-down modes.
- [ ] Count-down durations can be selected from 1m, 5m, 10m, 15m, 25m, 45m, 60m presets or entered manually.
- [ ] The selected interval repeats when the reset/repeat gesture is used.
- [ ] Completion plays one notification sound and shows a macOS notification.
- [ ] The notch-style island exposes mode, duration, start/stop, reset/repeat, drag, and quit controls.
- [ ] GitHub Actions builds a macOS `.zip` and `.dmg` without requiring Xcode or Terminal on the target Mac.
